# Project Instructions

This project is an AI-powered personal learning system.
Full specification is in specs.md. Read it before starting any task.

## Rules
- Python backend: FastAPI
- Database: SQLite via SQLModel
- Frontend: HTMX + Jinja2 templates (no React, no heavy JS frameworks)
- Streaming: Server-Sent Events
- Always create or update requirements.txt when adding dependencies
- Never hardcode API keys — use .env + python-dotenv
- Follow the build order in specs.md exactly — do not skip phases
- One phase at a time. Do not start Phase 2 until Phase 1 is complete and reviewed
